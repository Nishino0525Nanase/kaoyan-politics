# 知政 · 考研政治专题真题

2007—2026 年共 760 题：320 道单选、340 道多选、100 道分析题。按学科、固定二级专题、详细考点、年份与题型组织。

在线刷题：[GitHub Pages](https://nishino0525nanase.github.io/kaoyan-politics/)

提交到 `main` 后会自动校验题库并将 `dist/` 发布到 GitHub Pages。

## 使用

在发布网址打开。选择题提交后按完整答案判分；多选少选、错选均判错。分析题提供材料和参考作答要点，通过自评进入或移出错题本。学习记录保存在当前浏览器，可导出 JSON 备份并在其他设备导入。

## 源码

- `dist/`：独立静态网页，无构建依赖。
- `data/`：按年份分组的整理数据、专题映射、补充提示。
- `scripts/taxonomy.json`：固定二级专题表。
- `scripts/assemble.py`：从 `data/` 生成题库与完整性审计；可用首个参数指定其他输入目录。
- `scripts/verify.mjs`：完整性检查，以及在轻量 DOM 模型中运行真实页面脚本，验证筛选、判分、错题、收藏、分析题自评、保存恢复和备份导入。

```sh
python3 scripts/assemble.py
node --check dist/app.js
node scripts/verify.mjs
```
